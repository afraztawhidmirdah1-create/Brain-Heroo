BRAIN HERO — AFRAZ STUDIO
========================
Files:
- index.html      Main game
- questions.json  2,000 level question bank
- manifest.webmanifest  PWA manifest
- sw.js           Offline cache
- icons/          PWA icons

Run:
1. Serve this folder over HTTP/HTTPS (PWA service workers do not work from file://).
2. Open index.html in a modern browser.
3. Use Add to Home Screen / Install App.
4. To make an APK, wrap the PWA using a trusted PWA-to-APK/TWA packaging workflow.

Image note:
Question images use unique Picsum seed URLs so every level has a distinct image request. Replace those URLs with your own licensed real-life photographs if you want guaranteed documentary/real-world subject matching and full offline image storage.
